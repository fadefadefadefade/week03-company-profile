# Laravel and Blade FreshSpin Laundry Services Website

## 1. Project Overview

The project is a simple and professional **laundry service showcase website** developed using **Laravel and Blade**.

The website is designed for **FreshSpin Laundry Services**, a local laundry shop located in **Luisiana, Laguna**.

The main purpose of the website is to promote FreshSpin Laundry Services, introduce the business to potential customers, showcase its laundry services and prices, and provide customers with an easy way to find the shop's contact information.

The website will have a clean, modern, and laundry-themed design that is easy to navigate, especially on mobile devices.

The website will consist of four main pages:

1. Home
2. About
3. Services
4. Contact

The website will also use two reusable Blade components:

* Navigation Bar
* Footer

# 11. Technology

The website will be developed using:

* **Laravel** – PHP web application framework
* **Blade** – Laravel's templating engine
* **HTML** – Website structure
* **CSS** – Website styling
* **JavaScript** – Optional client-side interactions

Blade `@include()` will be used to include the reusable Navbar and Footer.

The project will initially focus on the **front-end presentation and Blade structure**.

Backend functionality for the customer inquiry form is **not required at this stage**.
